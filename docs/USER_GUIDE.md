# AI Vector Cleanroom — Designer Preview 4

**先留下可用的向量，難修的部分交給設計師。**

`v3-designer-preview.4` 是面向 Illustrator 接手流程的 Windows 原始碼預覽版。工具將 PNG、JPG、WebP、BMP 轉成 SVG，支援整張自動整理，然後直接匯出可編輯草稿。需要局部重畫時，也能標記「採用」「待確認」「交人工」。目標是減少後續整理負擔，而不是把每個像素都硬轉成更多碎路徑。

**目前沒有設計師實際省時比例，也未完成 Illustrator 匯入與完稿驗收。** 本機程式測試、瀏覽器預覽、節點數減少與幾何／渲染檢查，都不能替代設計師實際編輯、計時和交稿檢查。

Preview 4 改進接手時的問題定位。每個交接物件以真正可見的部分對照原圖，具體提醒顏色／粗細／透明度差異、明暗變化遺失，以及近白或透明位置上的多餘上色；不再只因物件外框碰到問題區就整組標記。遮擋、群組與半透明合成一起計算，沒有具體問題就不重複列出通用提醒。提示不會自動修改圖形或替你採用物件。

這項比對有原生影像大小、物件數、渲染量與時間上限；若缺少真正原圖、超過上限或比對失敗，頁面會說明尚未完成。沒有提示不代表已驗收。細長物件的新重建方案仍需獨立證據，不會單憑總面積接近就放寬原本的來源檢查。

這版改進的是「更容易接手」：對可確認的白底漸層物件，直接參考原圖邊緣重建；原圖沒有的小洞、縮圖產生的假漸層另行檢查。原有描圖結果不再被當成不可改變的標準答案。若原圖資訊不足，或修改會封住白縫、破壞筆畫，就保留原候選並列出待處理區域。細線會檢查原圖中的粗細、端點與交叉；淡漸層也不會只因色盤分成一色就直接放棄。

色彩與輪廓可以分開改善。如果無法安全減少節點，但原圖支持部分路徑共用漸層，程式會保留這項改善，並維持需要人工確認的狀態。這類結果仍有原來的多條路徑，不能當作已合成一個完整物件。

## 第一次使用

1. 安裝 **64 位元 CPython 3.12**，包含 Windows Python Launcher，確認可執行 `py -3.12`。
2. 保留完整原始碼目錄，雙擊 `setup_windows.bat`。第一次安裝需連網下載鎖定版本的依賴。
3. 安裝完成後雙擊 **`工作台.bat`**，瀏覽器會開啟本機工作台。
4. 拖入圖片，轉檔完成後按結果列的 **「設計師接手」**。

工作台通常位於 `http://127.0.0.1:8765/`；連接埠被占用時會尋找下一個可用埠，以啟動視窗顯示的網址為準。使用期間保留啟動視窗；關閉後，本機頁面的保存／匯出連結會停止回應。重新執行 `工作台.bat` 可讀取既有結果。

## 建議接手流程

**建議流程：轉檔 → 設計師接手 → 視需要自動整理整張圖 → 匯出接手包 → 在 Illustrator 開 working.svg。** 若想直接開始人工編輯，可以跳過自動整理。也不必先逐一分類物件；working.svg 會保留完整候選向量，參考圖預設隱藏。下列區域判斷是選用功能，適合需要分清採用與重畫範圍時使用。

1. **比對原圖與向量。** 可滾輪縮放、按住空白鍵拖曳平移、點圖選物件，或拖曳框選。框選需完整包住已知幾何邊界，避免連大背景一起選入；沒有可信範圍的物件請從右側列表選取。
2. **先看原圖差異，再看結構負擔。** 有原圖時，右側依物件實際可見像素列出色彩／覆蓋與明暗差異，再列出短曲線反覆轉彎、高節點等結構提醒；點選後放大確認。不確定屬於哪個物件的孔洞或連通問題，保留為全圖待查，不硬套給外框碰到它的每個物件。也能切換高節點排序、多選與批次判斷。分組沿用現有可辨識物件，不代表恢復原作者的語意或原始圖層。
3. **明確選擇處理方式。** 所有物件第一次開啟都在「待確認」；系統建議不會自動變成採用。用 `1 / 2 / 3` 切換採用／待確認／交人工，`Ctrl+Z` 復原，`Ctrl+Shift+Z` 重做。
4. **檢查「只看已採用」。** 被排除的遮擋物可能使底下形狀露出；只留下原幾何，不代表任意子集都能維持原來外觀。
5. **直接按「匯出 Illustrator 接手包」。** 成功匯出會一併保存當次判斷；只想保存分類時，再按「儲存判斷」。即使仍有待確認或交人工區域，也可以匯出接手草稿；畫面會保留剩餘數量，不會標成完全完稿。

| 狀態 | 用途 | 匯出後的處理 |
|---|---|---|
| 採用 | 這個物件可作為接手基礎 | 保留在 `accepted.svg`，也顯示在 `draft.svg` |
| 待確認 | 仍需檢查或試修 | 從採用檔排除；草稿保留隱藏候選及可定位的提示框 |
| 交人工 | 由設計師重畫或另行整理 | 同樣排除於採用檔，列入待處理清單 |

新轉檔會另外保存未去背的原圖參考。舊結果若只有清理後的參考圖，接手頁與匯出資料會明示「清理後參考圖（非原始圖片）」；它不能用來驗證原圖被清掉的細節。

## 接手包怎麼用

每次匯出另建獨立資料夾和 ZIP，不覆寫上一份接手包。

| 檔案 | 內容 |
|---|---|
| `working.svg` | 完整候選向量可直接編輯，35% 不透明度的描圖參考預設隱藏。不用先逐一標記採用；交人工的候選也保留，依清單自行取捨。含嵌入點陣參考，**不是純向量完稿。** |
| `draft.svg` | 已採用向量、35% 不透明度的點陣參考圖、隱藏候選與待處理提示框。**不是純向量完稿。** |
| `accepted.svg` | 僅含已採用物件。仍有未採用區域時，這是一份不完整的向量底稿。 |
| `handoff.json` | 待處理清單、參考圖種類、無法定位的物件與匯出狀態 |
| `handoff-manifest.json`、`handoff-decisions.json` | 物件資訊與這次匯出的判斷記錄 |
| `OPEN_IN_ILLUSTRATOR.txt` | Illustrator 接手步驟 |

在 Illustrator **先開 `working.svg`** 可直接修改完整候選；需要比對時再顯示並鎖定參考圖。想依原圖補畫、只留下已採用區域時，再用 `draft.svg`。請檢查透明度、漸層、孔洞與前後遮擋；SVG 匯入後的群組和顯示仍需人工確認。最後移除參考圖、提示框及不需要的隱藏候選，再另存 `.ai`。

本版不直接產生 `.ai`，不承諾自動恢復可編輯字型；文字在既有轉檔流程中通常是輪廓 path。

核對原色時，請看接手頁的原圖，或將 Illustrator 中的參考圖透明度調為 100%。整理後請從新版本的接手頁匯出；舊校稿頁與既有接手包不會自動更新。

## 整張自動整理

按「自動整理整張圖」後，程式逐區尋找安全的減點方式，已採用物件保持原狀。每條路徑獨立驗證：某處不能改善，不會使整張操作失敗，也不會硬套形狀。

- 支援封閉單色輪廓、可驗證的線性／放射漸層；使用原生 SVG 渲染器檢查實際漸層，並對照孔洞、透明裂縫、全圖與原圖局部差異。
- 整理搜尋預算為 180 秒、256 次候選嘗試、48,000 個輸入錨點；每條最多 4096 錨點、12 秒。最後檢查與保存另需時間。超出或不支援的部分原樣保留，清單列出原因。
- 新版本顯示減點數、保留區域與原圖重建數；被改動的區域回到待確認，已採用的幾何／樣式／堆疊保持相同。
- 同一路徑不反覆簡化累積誤差；要換容許誤差比較，從原版本另開。
- 原圖是白底、不透明、只有一個單色形狀且沒有孔洞時，會另試「依原圖重建橢圓」。只有原圖的輪廓、尖角、顏色、孔洞都合格，而且比原向量更貼近原圖，才保留原生四錨點橢圓。這是不同於保守減點的重建，畫面和報告會明示，仍需確認設計意圖。
- 整理後依最新 SVG 重建換色頁；不能完整支援的填色會明示不可用，不沿用舊版換色頁。

容許誤差是擬合參數，**不是免修改率**。百分比依輪廓包圍盒的對角線換算；95% 的採樣偏差須在設定值內，最大採樣偏差不得超過 3 倍，並另檢查尖角與每個小輪廓的自身尺度。例如設定 0.25% 時，最大採樣偏差仍可能達 0.75%；採樣檢查不是對所有曲線的數學證明。不要為了追求最少節點而強迫不規則造型變成規則形狀。

初次轉檔也會處理常見的規則圖形：獨立細直線會對照原圖估算位置、粗細與顏色，保留可調線寬的筆畫；原圖是單一白底、不透明的漸層圓或圓角矩形時，只有漸層模型能解釋原圖、孔洞與輪廓檢查通過，而且實際渲染誤差改善，才重建為四錨點圓或八錨點圓角矩形。邊緣碎片若要併入，也需逐處對照原圖確認沒有退步。多個獨立圖形、遮擋、複合孔洞、近白漸層或證據不足的情況不硬套。若某個漸層替換需要附加大量碎片，會撤回該替換，保留其餘可用成果。

漸層重建另有保留輪廓的路徑：當重畫外形不可靠，但原圖支持一個漸層時，可讓少量已有路徑共用同一個 SVG 漸層。只有實際渲染的透明覆蓋完全相同，而且原圖全景、每條路徑及其邊緣的誤差檢查通過，才替換填色。這不算合併物件或減點，也不會因恢復漸層就將複雜輪廓標成容易編輯。

轉檔偶爾會在有顏色的區域留下小假孔。只有原圖與處理後影像都支持補回，而且實際整張渲染及每個補回區域通過檢查，才移除對應的小孔輪廓；其他外輪廓與孔洞原樣保留。補孔和後續曲線整理分開驗證，報告也分開記錄兩者減少的節點。真正留白、模糊證據或另一物件的細節不會只因「看起來像雜點」就被吸收。

若補孔後整條漸層輪廓的簡化會造成裂縫，程式會另試有時間上限的分段整理。通過檢查的片段才減點，其他片段與孔洞保持既有幾何。每次都與同一份原輪廓、原圖及完整場景比較，不靠反覆簡化累積誤差；這是搜尋到的安全改善，不是數學上的最少節點證明。

## 局部減點：小範圍試修，另外保留版本

選取尚未採用的區域，按 **「僅簡化所選輪廓」**。可選保守 `0.1%`、標準 `0.25%`、較大 `0.5%` 幾何誤差預算。這些數值不是品質得分，也不是省工百分比。

這個操作針對**現有 SVG 輪廓減點，不會重新描繪原圖**。目前範圍刻意有限：

- 一次 1–4 個物件、合計最多 4 條路徑；每條路徑 5–512 節點、合計不超過 1536 節點。
- 僅支援封閉、明確單色填色 path。筆畫、漸層／資源依賴、文字、原生形狀、transform、遮罩、裁切與濾鏡等不在此模式支援範圍；選到不支援項目會拒絕本次要求，保留原稿與判斷。
- 處理子程序最多 60 秒；超時、未實際減點或檢查未過，不發布新版本。
- 大於 5 MiB 的 SVG、長寬比超過 8:1 的畫布，暫不支援此互動簡化。
- 新版本保留未選取及已採用物件的幾何、樣式與堆疊；被改動的物件回到「待確認」。
- 同一條路徑不可在衍生版本中反覆簡化。要比較其他誤差，回到原版本再試，避免累積漂移。

局部與整張渲染、孔洞／連通結構檢查通過，仍不等於已驗證原圖全部細節或完成整張設計驗收。新版本需要你重新目視確認；它不沿用舊版的整張驗收分數。

## 保存與版本

瀏覽器會暫存未保存的判斷；**按「儲存判斷」才會寫入工作台**，成功匯出也會保存該次判斷。重新開啟時，若本機草稿依據的版本與工作台相同，會恢復該草稿，並標示尚未保存。

保存、匯出及簡化都檢查 SVG 指紋與判斷版本（CAS）。另一視窗若先保存，舊視窗會收到衝突訊息，不會覆蓋新資料。重新開啟後，版本不同的草稿不自動套用：先顯示工作台已保存的判斷，同時保留本機草稿，提供 **「取回本機草稿，重新核對」** 與 **「下載保留草稿 JSON」**。取回只是載入畫面，仍須逐區核對並自行儲存，也可以復原到取回前；不會自動合併衝突或覆寫工作台。

已保存的採用物件會保護該結果免於原地重跑。工作台的 **「另開版本重跑」** 會產生獨立結果，原版判斷與已匯出的接手包保持可用。局部減點也另建版本。

## 安裝與資料位置

本版提供 MIT 授權原始碼，不內嵌 Python runtime，也不是可直接 `pip install ai-vector-cleanroom` 的套件。啟動器以 **Windows x64 + CPython 3.12 x64** 為目標；其他平台未列入本預覽版驗證範圍。

| 項目 | 預設位置 |
|---|---|
| 專用 Python 環境 | `%LOCALAPPDATA%\AI-Vector-Cleanroom\venvs\v3-designer-preview.4` |
| 工作資料 | `%LOCALAPPDATA%\AIVC\designer4` |
| 輸入／結果 | 工作資料下的 `input`／`output` |

這個預覽版使用獨立環境與資料目錄，不自動搬移 Beta.6 的 `%LOCALAPPDATA%\AIVC\b6` 資料，也不覆寫舊環境。更新原始碼或重跑 setup 不會清空工作資料。

需自訂時，在同一個命令提示字元視窗設定後啟動：

```bat
set "AVC_VENV_DIR=D:\venvs\aivc-designer4"
set "AVC_DATA_DIR=D:\AIVC-designer4"
setup_windows.bat
工作台.bat
```

請使用短的絕對本機路徑。自訂環境須為新路徑，或由本 setup 建立且有有效 ownership marker 的專用環境；程式不接管其他專案的 venv。Setup 會檢查鎖定版本、Python ABI 與必要套件，修復失敗時保留原環境。依賴鎖定見 `requirements/validated-py312.lock.txt`。

同一資料根目錄一次只允許一個寫入程序。不要放在 OneDrive、網路磁碟或多人共用的同步目錄。工作台只監聽 `127.0.0.1`，轉檔與接手資料保存在本機，不上傳圖片至外部服務；首次安裝依賴需連網。

## 批次與進階功能

把圖片放入資料根目錄的 `input`，再執行 `清稿.bat`；也可以指定路徑：

```bat
清稿.bat --input D:\vector-jobs\input --output D:\vector-jobs\output
```

CLI 的 `--input`／`--output` 優先於預設位置。要從工作台開啟這些結果，需使用相應資料根目錄。

本版承接 Beta.6 的轉檔、保守幾何／筆畫／漸層處理、校稿與換色功能。工作台轉檔預設最多 1200 秒（20 分鐘）、16 個候選，可取消；失敗與超時不發布不完整結果。複雜多色圖的完整來源與場景檢查可能需要超過 15 分鐘，此上限不是完成時間保證。`AVC_JOB_TIMEOUT_SECONDS` 可在 30–1800 秒間設定轉檔上限，不會放寬品質檢查，也不改變局部減點的 60 秒上限。同一轉檔內，完全相同的 SVG、來源、參考圖與候選參數會重用補孔／分段及局部漸層的場景證據；快取不跨工作保存，場景不同仍重驗。WebGPU 僅在相容且驗證通過的 palette-label 運算啟用，並非整體 GPU 轉檔；可設定 `AVC_GPU_MODE=cpu`。

其他歷史行為、失敗診斷與回滾紀錄見 [CHANGELOG.md](../CHANGELOG.md)。轉檔失敗診斷可能保存於資料根目錄 `.failed_jobs`，其中的部分輸出不是正式成品。

## 驗證邊界

先完成 setup，再執行 `tests\run_tests.bat` 可跑程式回歸測試。這是程式與合成圖例檢查，**不等於 Illustrator 已驗收，也不等於設計師實際省時**。

工作台保留視覺盲評與「Stage 2 實作計時」入口。要評估這個工具是否值得採用，應讓設計師用實際工作圖片，分別計時「從工具草稿完成指定修改」及「從頭重畫」，並記錄需整區重畫、匯入失真與接手失敗的情況。尚未取得這些實測前，不承諾免修改率或省工比例。
