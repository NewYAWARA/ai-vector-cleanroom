# v0.6.0-alpha 改版說明

版本：`v0.6.0-alpha` · 2026-10-06 · **原始碼預發布版**

[English — full release notes](https://github.com/NewYAWARA/ai-vector-cleanroom/blob/v0.6.0-alpha/release/RELEASE_NOTES.en.md)

## 這次發布改了什麼

這次將公開版本號接回既有的 `v0.5.0-alpha → v0.6.0-alpha` 系列，並補齊完整繁體中文與英文 README、使用指南及發布說明。先前公開的 `v3-designer-preview.4` tag 與 Release 保留，方便追查歷史。

**相較 Designer Preview 4，轉檔、整理、接手診斷與匯出行為沒有改變。** 這是公開編號、文件與發行資訊的修正，不是又一輪畫質改善。專用 Python 環境改用 `v0.6.0-alpha` 名稱；工作資料仍使用與 Preview 4 相容的 `AIVC\designer4` 目錄。

工具的目標仍是讓設計師更容易接手、保留可用成果並補畫難處。它不是一鍵完稿版，也沒有經設計師實測證實省工比例。以下功能變更是**相較較早的公開版 `v0.5.0-alpha`**，不是全部在本次編號修正中新增。

## 相較 v0.5，設計師會用到的變更

- **完整接手流程。** 原圖與向量左右比對，能選取、放大與批次標記「採用／待確認／交人工」。不必先替所有物件分類，就能匯出完整候選去 Illustrator 接著改。
- **整理後另留版本。** 整張自動整理與受限的局部減點，讓可處理部分先改善；未通過檢查的部分保留，已採用物件受到保護。重跑、保存與多視窗操作加入版本核對，避免過期操作覆寫較新的判斷。
- **回到原圖判斷部分輪廓與孔洞。** 對支援的情況，依原圖邊緣提出輪廓重建，並檢查假孔、白縫與新裂縫。中間描圖結果不再是唯一依據。證據不足或會破壞其他區域時保留原候選。
- **分開評估顏色與形狀。** 支援條件內，輪廓無法安全簡化時，仍可保留通過來源檢查的漸層填色改善；不把只改填色算成合併物件成功。
- **具體問題定位。** 依每個接手物件真正可見的部分對照原圖，提醒色彩或覆蓋範圍不同、留白處多餘上色、明暗變化遺失。移除重複通用提醒；全圖結構疑點另列，不因外框相交就歸到每個大物件上。選取框不再把細線染色，方便比色。
- **Windows 安裝與資料分離。** 使用專用 CPython 3.12 x64 環境與鎖定依賴，工作資料放在獨立的本機目錄。轉檔有進度、取消與時間上限；失敗或超時不當成完整成果發布。

原版已有的 SVG 筆畫、規則形狀、漸層、分組、換色與校稿功能繼續保留。本次沒有把它們全算成新增，也不保證每個物件都能變成可調線寬的筆畫或單一漸層。

Preview 4 的主要更新是接手診斷，本版完整承接。研究中的細長物件重建仍未加入預設管線，也沒有為了讓候選通過而直接放寬既有來源檢查。

## 匯出後先開 working.svg

- **`working.svg`**：完整候選向量，加上預設隱藏的嵌入原圖參考。適合直接開始人工編輯；它不是純向量完稿。
- **`accepted.svg`**：只有手動採用的部分。初始全部物件都是待確認，因此未作判斷的第一次匯出會是空白。
- **`draft.svg`**：採用部分、點陣參考、隱藏候選和定位提示，方便補畫，同樣不是純向量完稿。
- 接手包另附清單、判斷 JSON 和 `OPEN_IN_ILLUSTRATOR.txt`。每次匯出另存一份，不覆寫前一份接手包。

完成後請移除參考圖、提示框及不需要的隱藏候選，檢查透明度、孔洞、漸層和遮擋，再另存 `.ai`。工具不直接輸出 `.ai`，文字通常仍是輪廓，無法可靠恢復原字型。

## 安裝與更新

1. 準備 Windows x64 與 CPython 3.12 x64，含 Python Launcher。
2. 下載 `AI-Vector-Cleanroom-v0.6.0-alpha.zip`，解壓到新目錄，執行 `setup_windows.bat`；第一次需連網安裝鎖定依賴。
3. 關閉仍在使用同一資料目錄的舊工作台，再執行 `工作台.bat`。英文檔名入口 `workbench.bat` 行為相同。

預設環境為 `%LOCALAPPDATA%\AI-Vector-Cleanroom\venvs\v0.6.0-alpha`；資料仍為 `%LOCALAPPDATA%\AIVC\designer4`。**Preview 4 使用者會沿用同一資料目錄，既有結果與已保存判斷不因版本名稱改變而失效；這次升級不會自動搬移或重跑資料。** 較早版本的其他資料目錄不會自動匯入。請保留舊輸出與接手包，不要直接覆蓋仍在執行的程式目錄，也不要同時開兩個工作台寫入同一資料目錄。

若曾把 `AVC_VENV_DIR` 指向 Preview 4 的環境，新版 setup 會因環境版本標記不同而拒絕沿用。請清除該覆蓋設定以使用新版預設環境，或指定全新的目錄；不要手動改環境標記。自訂 `AVC_DATA_DIR` 的用法與工作資料不受這項環境名稱修正影響。

本版不附 Python runtime。驗證環境為 Windows x64 / CPython 3.12.x，其他平台與 Python 版本尚未正式驗證。發行收據為 `SOURCE_RELEASE_RECEIPT_v0.6.0-alpha.json`。

操作細節見 [繁體中文 README](https://github.com/NewYAWARA/ai-vector-cleanroom/blob/v0.6.0-alpha/README.md)、[繁體中文完整指南](https://github.com/NewYAWARA/ai-vector-cleanroom/blob/v0.6.0-alpha/docs/USER_GUIDE.md)、[English README](https://github.com/NewYAWARA/ai-vector-cleanroom/blob/v0.6.0-alpha/README.en.md) 及 [full English guide](https://github.com/NewYAWARA/ai-vector-cleanroom/blob/v0.6.0-alpha/docs/USER_GUIDE.en.md)。

## 已知限制與驗證範圍

- 文字內部、細光芒、淡尖端、色帶、相接邊緣與局部顏色仍可能需要人工修改或重畫。有些區域可能較 v0.5 退步，不能只看整體平均誤差。
- 提示可能漏報或過多，排序也不等於設計重要性或修改工時。沒有提示、較少節點或機器標記通過，都不代表可直接交件。
- 複雜柔邊、陰影、紋理、照片和原字型恢復不是這版主力。分組也不代表還原作者的語意或原始圖層。
- 先前凍結的 Preview 4 開發版本機紀錄為 **975 項 unittest，5 項跳過，0 失敗**；另重跑 36 張合成基準，33 張機器判定接受、3 張要求人工確認。36 張已知正確圖的診斷負控制未觸發新差異提示。這些是先前版本的有限範圍證據，不是本次公開提交已完成相同驗證的聲明，也不能推論所有真圖都沒有誤報或退步。
- **尚無 Illustrator 實機匯入／完稿驗收，也尚無設計師對照計時。** 測試數量不是品質分數或省工比例；本次公開提交的檢查以該次 CI 與發行檢查為準。需要私有素材而跳過的測試不能當作通過。

可以附可公開的最小反例；不要提交客戶、私人或授權不明的圖稿。公開原始碼保留程式生成的合成測試素材，正式素材、內部研究輸出與本機驗證資料不隨發行包發布。
