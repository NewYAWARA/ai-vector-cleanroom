 AI 向量清稿工具 — v0.6.0-alpha
 v0.6.0-alpha · 2026-10-06
================================================

公開版號承接 v0.5.0-alpha；本版轉檔與接手功能與先前 Preview 4 相同。
完整英文說明請看 README.en.md 和 docs/USER_GUIDE.en.md。

先留下可用的向量，難修的地方交給設計師。
這版的目標是方便 Illustrator 接手，不是保證一鍵完稿。
本機測試與瀏覽器預覽，不等於 Illustrator 匯入驗收或設計師實測。
目前沒有實際省工比例或免修改率的承諾。

Preview 4 新增逐物件的可見像素原圖比對。
右側具體提示顏色／粗細／透明度差異、遺失明暗變化和原圖留白處上色。
不再只因外框相交就整組警告；沒有具體理由的物件不重複掛通用提醒。
提示不自動修圖或採用。未檢查、超過計算上限與沒有找到提示會分開顯示。

【第一次開啟】
1. 安裝 Windows 64 位元 CPython 3.12，包含 Python Launcher。
2. 在完整原始碼目錄雙擊 setup_windows.bat，等待安裝完成。
   首次安裝需連網下載鎖定版本的依賴；此版本不內嵌 Python runtime。
3. 雙擊「工作台.bat」。瀏覽器會開啟本機工作台。
   通常是 http://127.0.0.1:8765/；以啟動視窗顯示網址為準。
4. 把 PNG、JPG、WebP、BMP 拖進頁面，等待轉檔。
5. 在結果列按「設計師接手」。請保留工作台的啟動視窗。

【接手頁：建議操作順序】
建議接手：視需要按「自動整理整張圖」，再匯出接手包，開啟 working.svg。
若想直接開始人工編輯，可以跳過自動整理，直接匯出 working.svg。
不用逐一把所有物件按過「採用」。整理失敗的部分會保留原候選，不強改。
下列判斷與分類適合只想保留部分成果、其餘重新描畫的情境。

1. 左右比對參考圖與向量。滾輪縮放，空白鍵＋拖曳平移。
   新轉檔有未去背的原圖參考；舊結果若只有清理後參考圖，會明確標示，
   不應用它判斷原圖中可能已被去除的細節。
2. 點圖選物件，或拖曳框選；Shift、Ctrl 可多選，右側列表可批次選取。
   框選需完整包住物件的已知幾何範圍，避免連同大片背景一起選入；沒有範圍的物件，請從列表選取。
3. 優先檢查原圖白縫填住、筆畫斷開或白底多出色塊的提示，再看短曲線反覆轉彎與高節點區域。
   可以切換「節點多的優先」。提示是定位待檢查處，不代表造型已正確還原，
   也未證明重畫一定比較快。
4. 所有物件初始都是「待確認」，系統建議不會自動採用。
   採用：保留這個物件作為向量接手基礎。
   待確認：仍需比較、檢查或試修。
   交人工：由設計師自行補畫或重新整理。
5. 一次選多個物件，可批次改狀態；1／2／3 是對應快捷鍵。
   Ctrl+Z 復原，Ctrl+Shift+Z 重做。
6. 按「只看已採用」，確認留下的部分。移除前景遮擋後可能露出底下形狀，
   請檢查孔洞、露底和前後順序，不能只看節點變少。
7. 可直接按「匯出 Illustrator 接手包」，成功時會一併保存當次判斷。
   只想保存分類時，再按「儲存判斷」。
   仍有待確認／交人工的物件也能匯出草稿，畫面不會將它稱為完全完稿。

【拿到 ZIP 後，在 Illustrator 做什麼】
解壓接手包，先讀 OPEN_IN_ILLUSTRATOR.txt。

  working.svg
    完整可編輯的向量候選，無論是否按過「採用」都會顯示。
    35% 不透明度的描圖參考放在隱藏群組；需要時可在 Illustrator 物件面板開啟。
    適合直接修線條、節點、顏色；仍是待校稿的向量草稿。
  draft.svg
    接手草稿。含已採用向量、35% 不透明度的點陣參考圖、隱藏候選，
    以及可定位的待處理框。不是純向量完稿。
  accepted.svg
    只含已採用向量；若仍有未採用區域，它就是不完整的向量底稿。
  handoff.json
    待處理區域、參考圖種類、無法定位的物件及匯出資訊。
  handoff-manifest.json / handoff-decisions.json
    這次匯出的物件資料與判斷記錄。

直接修改請用 Illustrator 開啟 working.svg；只接續已採用部分並補畫，
請開啟 draft.svg，在圖層／物件面板檢查並鎖定參考圖。
SVG 匯入的顯示與分組仍須檢查，尤其是透明度、漸層、
文字輪廓、孔洞與遮擋。自動群組不等於原作者的物件結構。
完稿前移除參考圖、提示框和不需要的隱藏候選，再另存 .ai。
本工具不直接產生 .ai，也不會把文字自動還原成可編輯字型。
核對原色請看接手頁原圖，或把 Illustrator 中參考圖的透明度調為 100%。
整理後請從新版本接手頁匯出；舊校稿頁與既有接手包不會自動更新。

【自動整理整張圖】
系統先嘗試節點較多的物件，整理搜尋預算為 180 秒；每路徑最多 12 秒。
最後檢查、保存新版本與重建換色頁另需時間。
已採用的物件保留不動；其餘最多嘗試 256 路徑、總計 48000 節點。
支援範圍內會分別檢查原圖、實際 SVG 渲染、形狀與孔洞，再決定是否保留改動。
沒有改善就維持原版本；有改善則另開版本，保留原稿與判斷。

整理包含兩種方式：
- 簡化既有輪廓：在受控誤差內減少節點，不把所有小轉折都當作必須保留。
- 依原圖重建橢圓：只有明確、不透明、單色、無洞、無內部細節的獨立形狀，
  通過原圖檢查才改成 4 節點曲線。模糊、不規則或有其他細節時不硬套。

部分漸層可保留可調整的 SVG 漸層；複雜材質、遮擋、筆畫與資源依賴並非
全部可自動整理。頁面逐物件列出改動與略過原因，可直接定位檢查。
初次轉檔也會對照原圖，嘗試把單一漸層圓／圓角矩形整理成 4／8 節點的
原生形狀；只在輪廓、顏色與細節檢查通過時採用，不強迫複雜圖形套用。
這些是軟體檢查，不代表真人已認可造型，也不等於 Illustrator 匯入驗收。

【僅簡化所選輪廓】
這是現有 SVG 的局部減點，不是把原圖重新描一次。
只有選取的物件全部不是「採用」時，按鈕才可用。

  保守 0.1% / 標準 0.25% / 較大 0.5%
  這是幾何誤差預算，不是品質分數，也不是省工比例。
  依輪廓對角線換算，95% 採樣偏差須在設定值內，最大採樣偏差不超過 3 倍；
  例如標準 0.25% 的最大採樣偏差可達 0.75%。小孔、尖角與透明裂縫另檢查。

目前只支援明確單色填色、封閉的 path：
- 一次 1–4 個物件，合計最多 4 路徑；每路徑 5–512 節點，總計最多 1536。
- 筆畫、漸層／資源依賴、原生形狀、文字、transform、mask、clip、filter
  等目前不支援。選到不支援項目會拒絕要求，保留原稿與判斷，不強轉。
- 處理子程序最多 60 秒。沒有實際減點，或幾何、渲染、局部孔洞／連通結構
  檢查沒通過，就不產生新版本。
- SVG 大於 5 MiB 或畫布長寬比超過 8:1，目前也不支援此互動簡化。
- 成功後另外開啟衍生版本，未選取與已採用物件的幾何、樣式、堆疊保留。
  改過的物件回到「待確認」，不沿用舊版的整張驗收分數。
- 同一物件不允許在衍生版中反覆精修；請回原版比較另一個誤差設定。

局部檢查通過仍須人工目視確認，不代表原圖品質或整張設計已驗收。

【保存、衝突與重跑】
- 瀏覽器暫存不是工作台保存。按「儲存判斷」才寫入工作台；成功匯出
  也會保存當次判斷。重新開啟時，若本機草稿依據的版本與工作台相同，
  會恢復未保存草稿，並標示尚未保存。
- 多個視窗同時處理時，保存／匯出／簡化會檢查版本（CAS）。別的視窗
  若已保存，過期頁面會拒絕寫入，不覆蓋他人的較新判斷。
- 衝突時當前畫面與判斷仍在。重新開啟後，版本不同的草稿不自動套用：
  先顯示工作台紀錄，另保留本機草稿，可按「取回本機草稿，重新核對」，
  或「下載保留草稿 JSON」。取回後仍需逐區核對、自行儲存，也可復原。
  系統不會自動合併衝突或覆寫工作台紀錄。
- 已保存的採用物件受保護，不能原地重跑。工作台「另開版本重跑」會
  另建結果，既有版本、判斷及已匯出接手包仍保留。
- 每次匯出產生新資料夾／ZIP，不覆寫上一份接手包。

【資料與環境位置】
  專用 Python 環境：
    %LOCALAPPDATA%\AI-Vector-Cleanroom\venvs\v0.6.0-alpha
  工作資料：
    %LOCALAPPDATA%\AIVC\designer4
  圖片與結果：
    工作資料\input
    工作資料\output\result_名稱
  接手包：
    對應結果資料夾\handoff_隨機名稱\ 及同名 ZIP

本版不自動搬移 Beta.6 的 b6 資料，也不覆寫 Beta.6 的 Python 環境。
designer4 是沿用的開發期儲存目錄名稱，不是公開版號。啟動新版前先關閉舊工作台。
搬動原始碼、重新解壓或重跑 setup，不會自動清空工作資料。
若需指定位置，於同一個命令提示字元視窗設定後再啟動：

  set "AVC_VENV_DIR=D:\venvs\aivc-v060"
  set "AVC_DATA_DIR=D:\AIVC-designer4"
  setup_windows.bat
  工作台.bat

請使用短的絕對本機路徑，不要使用 OneDrive、網路磁碟或多人同步資料夾。
自訂環境須為新路徑，或本 setup 建立的專用環境；不接管其他專案的 venv。
如果 AVC_VENV_DIR 仍指向舊開發環境，先清除此設定或換成新路徑，再執行 setup。
舊環境的版本標記不相容，請勿手動修改標記檔。
同一資料根目錄一次只允許一個寫入程序。

【批次與既有功能】
把圖片放進工作資料的 input，雙擊「清稿.bat」，結果放在 output。
也可指定路徑：
  清稿.bat --input D:\vector-jobs\input --output D:\vector-jobs\output

原有校稿、換色、保守幾何／筆畫／漸層處理與診斷仍保留。
工作台轉檔預設 1200 秒（20 分鐘）、最多 16 候選，可取消；失敗不提交不完整結果。
複雜多色圖的完整來源與場景檢查可能超過 15 分鐘，上限不是完成時間保證。
AVC_JOB_TIMEOUT_SECONDS 可設 30–1800 秒，只調整轉檔時間，不放寬品質檢查，
也不改變局部簡化 60 秒上限。失敗診斷可能存於 .failed_jobs，並非正式成品。
同一工作內的完全相同場景可重用補孔／分段及局部漸層檢查；來源、SVG、
參考圖或候選參數不同就重驗。快取只存在該次轉檔記憶體，不跨工作保存。

【驗證與隱私】
- setup 後執行 tests\run_tests.bat，可跑程式回歸測試。通過不代表
  Illustrator 已驗收，更不能換算真人省時。
- 工作台保留 Stage 2 實作計時。請用真實工作圖比較「接手後完成指定修改」
  與「從頭重畫」所需時間，同時記錄失敗或需整區重畫的結果。
- 工作台只監聽 127.0.0.1；圖片、輸出與判斷保存在本機，不上傳外部服務。
  首次 setup 連網安裝依賴，與圖片轉檔資料無關。
- 工作台關閉後，本機保存／下載連結會停止回應。重新雙擊「工作台.bat」
  可讀取既有結果，不會自動重跑。
